# NET Core, API RESTful, SQL Server, JWT autenticación, backend profesional, Desarrollo web con C#.

## Descripción

Este proyecto consiste en el desarrollo de una API REST utilizando **.NET 8**, con el objetivo de aplicar buenas prácticas de desarrollo backend y construir una aplicación robusta, segura y escalable. El proyecto se desarrolla como parte de un proceso de aprendizaje práctico, simulando un entorno de trabajo real.

A lo largo del desarrollo se implementarán funcionalidades comunes en aplicaciones empresariales, como la gestión de entidades, persistencia de datos con **SQL Server** y **Entity Framework Core**, autenticación mediante **JWT**, autorización basada en roles, versionado de la API, paginación, carga de archivos y otras características orientadas a crear un backend moderno.

Además de la implementación de las funcionalidades, el proyecto seguirá principios de arquitectura limpia y organización del código, utilizando patrones como el **Repositorio** para mantener una estructura mantenible y escalable. La API contará con documentación interactiva mediante **Swagger/OpenAPI** y se realizarán pruebas de los endpoints utilizando **Postman**, incluyendo colecciones organizadas para facilitar su consumo y validación.

## Objetivos

* Desarrollar una API REST profesional con .NET 8.
* Implementar operaciones CRUD para las diferentes entidades del sistema.
* Integrar SQL Server mediante Entity Framework Core.
* Aplicar autenticación con JSON Web Tokens (JWT) y autorización por roles.
* Implementar validaciones, manejo de errores y respuestas estructuradas.
* Incorporar versionado, paginación y carga de archivos.
* Documentar la API con Swagger/OpenAPI.
* Crear y mantener colecciones de Postman para probar y consumir los endpoints.
* Aplicar buenas prácticas de desarrollo backend y preparar la aplicación para un entorno de producción.
